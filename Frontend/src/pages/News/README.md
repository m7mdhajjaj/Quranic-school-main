# News Page - صفحة الأخبار

صفحة الأخبار والفعاليات في أكاديمية المهاجرين لتعليم القرآن الكريم.

## 📁 البنية الحالية

```
News/
├── components/           # المكونات الفرعية
│   ├── NewsHeader.tsx   # رأس الصفحة مع زر الإضافة
│   ├── NewsCard.tsx     # بطاقة عرض الخبر الواحد
│   ├── NewsModal.tsx    # نافذة إضافة/تعديل الأخبار
│   ├── EmptyState.tsx   # حالة عدم وجود أخبار
│   ├── SocketIndicator.tsx  # مؤشر اتصال Socket
│   └── index.ts         # تصدير جميع المكونات
├── hooks/               # الـ Hooks المخصصة
│   └── useNewsData.ts   # Hook لإدارة بيانات الأخبار
├── utils/               # الأدوات والأنواع
│   └── types.ts         # تعريفات TypeScript
├── News.tsx             # الصفحة الرئيسية
├── index.ts             # التصدير الرئيسي
└── README.md            # هذا الملف
```

## 🎯 المميزات

### 1. **NewsHeader** - رأس الصفحة
- عرض العنوان والوصف
- زر إضافة خبر جديد (للمعلمين والمدراء فقط)
- تأثيرات حركية AOS

### 2. **NewsCard** - بطاقة الخبر
- عرض صورة الخبر مع تأثير hover
- عنوان وتاريخ ومحتوى الخبر
- أزرار التعديل والحذف (للمعلمين والمدراء)
- معالجة أخطاء تحميل الصور

### 3. **NewsModal** - نافذة الإضافة/التعديل
- نموذج شامل لإضافة/تعديل الأخبار
- رفع الصور إلى Cloudinary
- معاينة الصورة قبل الرفع
- التحقق من نوع وحجم الملف

### 4. **EmptyState** - حالة الفراغ
- رسالة ودية عند عدم وجود أخبار
- عرض رسائل الأخطاء
- زر إعادة المحاولة

### 5. **SocketIndicator** - مؤشر الاتصال
- يظهر فقط في وضع التطوير
- يعرض حالة الاتصال بالـ Socket
- معلومات الـ Socket ID وآخر تحديث

### 6. **useNewsData** - Hook مخصص
- إدارة جميع state الصفحة
- معالجة جميع العمليات (CRUD)
- اتصال Socket للتحديثات الفورية
- معالجة رفع الصور

```typescript
  // استخدام البيانات والوظائف

```

## 🔧 الوظائف الرئيسية

### في useNewsData Hook:

- **loadNews()**: تحميل جميع الأخبار من الـ API
- **refreshNews()**: إعادة تحميل الأخبار (للتحديثات)
- **handleAddNews()**: إضافة خبر جديد
- **handleEditNews()**: تعديل خبر موجود
- **handleDeleteNews()**: حذف خبر
- **handleFileChange()**: معالجة تحديد ملف الصورة
- **handleOpenModal()**: فتح نافذة الإضافة
- **handleCloseModal()**: إغلاق النافذة وإعادة تعيين البيانات

## 🎨 التخصيص

### إضافة مكون جديد:
1. أنشئ الملف في `components/`
2. أضف التصدير في `components/index.ts`
3. استخدمه في `News.tsx`

### تعديل الأنواع:
- عدل `utils/types.ts` لإضافة أو تعديل الأنواع
- الأنواع متاحة لجميع المكونات

### إضافة وظائف جديدة:
- أضف الوظائف في `hooks/useNewsData.ts`
- صدّرها من الـ Hook
- استخدمها في المكونات

## 🔌 Socket Integration

الصفحة متصلة بـ Socket.IO للتحديثات الفورية:
- عند إضافة خبر من جهاز آخر، يتم التحديث تلقائياً
- عند تعديل أو حذف خبر، يتم التحديث فوراً
- مؤشر الاتصال يظهر في وضع التطوير

## 📱 الاستجابة

الصفحة مصممة لتعمل بشكل مثالي على:
- الهواتف المحمولة (شبكة عمود واحد)
- الأجهزة اللوحية (شبكة عمودين)
- أجهزة الكمبيوتر (شبكة عمودين)

## 🔒 الصلاحيات

- **الطلاب**: عرض الأخبار فقط
- **المعلمون والمدراء**: عرض + إضافة + تعديل + حذف

## 🚀 المستقبل

أفكار للتطوير:
- إضافة نظام التصنيفات
- إضافة نظام البحث والفلترة
- إضافة التعليقات على الأخبار
- إضافة نظام الإعجابات
- إضافة نظام المشاركة على وسائل التواصل

## 📝 ملاحظات

- جميع الصور تُرفع على Cloudinary
- الحد الأقصى لحجم الصورة: 5MB
- أنواع الصور المدعومة: PNG, JPG, GIF
- التواريخ بصيغة ISO (YYYY-MM-DD)
