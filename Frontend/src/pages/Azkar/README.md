# صفحة الأذكار 📿

## البنية الجديدة

تم نقل كل ما يخص الأذكار إلى مجلد واحد منظم داخل `pages/Azkar`:

```
pages/
└── Azkar/
    ├── index.tsx                    # المكون الرئيسي للصفحة
    ├── components/                  # المكونات الخاصة بالأذكار
    │   ├── AzkarCategoryCard.tsx   # بطاقة فئة الأذكار
    │   ├── AzkarHeader.tsx          # هيدر صفحة الذكر
    │   ├── DhikrCard.tsx            # بطاقة الذكر الواحد
    │   ├── InfoMessage.tsx          # رسالة معلومات
    │   └── PageHeader.tsx           # هيدر الصفحة الرئيسية
    └── hooks/
        └── useAzkar.ts              # Hook إدارة حالة الأذكار
```

## المميزات

### 1. **التنظيم** 📁
- كل ملفات الأذكار في مكان واحد
- سهولة الصيانة والتطوير
- فصل واضح بين المكونات والـ Hooks

### 2. **المكونات** 🧩

#### `index.tsx`
- المكون الرئيسي للصفحة
- يعرض قائمة الفئات أو تفاصيل الفئة المختارة

#### `components/AzkarCategoryCard.tsx`
- بطاقة فئة الأذكار
- تعرض الأيقونة، العنوان، التقدم
- تدعم حالة الإكمال الكامل

#### `components/AzkarHeader.tsx`
- هيدر صفحة الذكر المحدد
- يستخدم `PageHeader` من shared
- يحتوي على أزرار الرجوع والإعادة

#### `components/DhikrCard.tsx`
- بطاقة الذكر الواحد
- تستخدم مكون `Reveal` للانيميشن
- تعرض النص، العداد، شريط التقدم

#### `components/InfoMessage.tsx`
- رسالة معلومات توضيحية
- تظهر في الصفحة الرئيسية

#### `components/PageHeader.tsx`
- wrapper لـ `PageHeader` من shared
- يضيف أيقونة وعنوان مخصص للأذكار

### 3. **Hook: useAzkar** 🎣

يدير كل حالة الأذكار:
- تحميل البيانات من localStorage
- حفظ التقدم
- إعادة تعيين يومية تلقائية
- دوال التحكم (handleDhikrClick, resetCategory)

#### البيانات المخزنة
- `azkar_data`: بيانات الأذكار الحالية
- `azkar_date`: تاريخ آخر تحديث (للإعادة اليومية)

## الاستخدام

```tsx
import Azkar from './pages/Azkar';

// في App.tsx
<Route path="/azkar" element={<Azkar />} />
```

## المكونات المشتركة المستخدمة

من `components/shared`:
- `PageHeader` - للعنوان الرئيسي
- `Card` - للبطاقات
- `Button` - للأزرار
- `Badge` - للشارات
- `ProgressBar` - لشريط التقدم
- `Reveal` - لتأثيرات الانيميشن

## الميزات المتقدمة

### 1. **الحفظ التلقائي** 💾
- يحفظ التقدم في localStorage تلقائياً
- لا تضيع البيانات عند إعادة تحميل الصفحة

### 2. **الإعادة اليومية** 🔄
- تتم إعادة تعيين العدادات تلقائياً كل يوم
- التحقق يتم كل دقيقة وعند تحميل الصفحة

### 3. **إشعارات الإكمال** 🎉
- عند إكمال فئة كاملة، يظهر إشعار SweetAlert
- الرجوع التلقائي للصفحة الرئيسية بعد الإغلاق

### 4. **تأثيرات الانيميشن** ✨
- استخدام مكون `Reveal` لظهور تدريجي
- تأخير متدرج بين البطاقات (index * 0.1s)
