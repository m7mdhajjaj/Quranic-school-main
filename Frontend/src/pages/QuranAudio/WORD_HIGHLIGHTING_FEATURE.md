# ميزة تمييز الكلمات أثناء قراءة القرآن الكريم

## نظرة عامة
تم إضافة ميزة تمييز الكلمات (Word Highlighting) في صفحة القرآن الصوتي، والتي تعرض تأثيرًا بصريًا جميلًا على الكلمات أثناء تشغيل السورة.

## المميزات الرئيسية

### 1. تمييز الآية النشطة
- عندما يتم تشغيل سورة، تُبرز الآية التي يتم قراءتها حاليًا
- خلفية ملونة بتدرج أخضر زمردي
- حدود ملونة وظل للكارد
- رقم الآية يتم تكبيره مع حلقة ملونة

### 2. تأثير متحرك على الكلمات
- كل كلمة في الآية النشطة تحصل على تأثير متحرك
- التأثير يعمل بشكل متتابع (staggered animation)
- الكلمات تتغير لونها وحجمها بشكل سلس
- Animation تعمل بشكل متكرر أثناء قراءة الآية

### 3. التمرير التلقائي (Auto-scroll)
- عند تغيير الآية، تتمرر الصفحة تلقائيًا للآية النشطة
- التمرير سلس وسهل على العين
- يضمن أن المستخدم يرى دائمًا الآية التي يتم تلاوتها

### 4. زر التحكم في التمييز
- يمكن للمستخدم تفعيل/إيقاف تمييز الكلمات
- واجهة سهلة الاستخدام مع أيقونة وشرح واضح
- الإعدادات تبقى مفعلة طوال الجلسة

### نظام التوقيت الدقيق للآيات

يستخدم النظام **نهج مزدوج** لضمان أفضل تزامن ممكن:

#### 1. التوقيت الدقيق (Preferred)
- يحاول أولاً الحصول على بيانات توقيت حقيقية من Backend
- كل آية لها `startTime` و `endTime` دقيقة
- يدعم توقيت الكلمات الفردية (future enhancement)

```typescript
interface AyahTiming {
  ayahNumber: number;
  startTime: number;    // بالثواني
  endTime: number;      // بالثواني
  words?: WordTiming[]; // توقيت كل كلمة (اختياري)
}
```

#### 2. التقدير الذكي (Fallback)
- إذا لم تتوفر بيانات حقيقية، يتم التقدير بناءً على:
  - مدة التسجيل الصوتي الفعلية (من metadata)
  - عدد الآيات في السورة
  - توزيع متساوي مع تحسينات للآيات الطويلة/القصيرة

```typescript
const getCurrentAyahFromTime = (
  currentTime: number,
  ayahTimings: AyahTiming[]
): number | null => {
  // البحث عن الآية الصحيحة بناءً على الوقت الحالي
  for (const timing of ayahTimings) {
    if (currentTime >= timing.startTime && currentTime < timing.endTime) {
      return timing.ayahNumber;
    }
  }
  return null;
}
```

### مميزات النظام الجديد
✅ **دقة عالية**: استخدام بيانات توقيت حقيقية عندما تكون متاحة
✅ **تزامن محسّن**: تحديث فوري عند تغيير الآية
✅ **لا تأخير**: event listener على `timeupdate` بمعدل تحديث عالي
✅ **Fallback ذكي**: تقدير محسّن عند عدم توفر بيانات حقيقية
✅ **أداء ممتاز**: استخدام `requestAnimationFrame` للتمرير السلس
