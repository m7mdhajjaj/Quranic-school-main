# AI Chatbot - نقل من Frontend إلى Mobile

## نظرة عامة

تم نقل مكون الـ AI Chatbot من Frontend إلى المحمول بنجاح مع الحفاظ على جميع الوظائف والتصميم.

## المعايير المتبعة

✅ **التصميم**: تم نقل نفس التصميم المجيب (Responsive) من شاشة الهاتف في الويب إلى تطبيق الموبايل  
✅ **الوظائف**: تم نقل نفس الوظائف بدون زيادة أو نقصان  
✅ **الترتيب**: تم المحافظة على نفس الترتيب والتقسيم

## الملفات المضافة

### 1. Types (`Mobile/my-app/types/aiChat.ts`)

- `AiMessage`: واجهة لرسائل الدردشة
- `AiChatState`: حالة الدردشة
- `AiChatResponse`: استجابة API

### 2. الشاشة الرئيسية (`Mobile/my-app/app/(tabs)/ai-chat.tsx`)

- شاشة كاملة للمحادثة مع الذكاء الاصطناعي
- نفس تصميم Frontend مع تكييف مناسب لـ React Native
- معالجة أفضل للأخطاء مع رسائل مخصصة
- إمكانية مسح المحادثة
- تحسينات بصرية ورسائل ترحيبية محسنة

### 3. تحديث DrawerMenu (`Mobile/my-app/components/Layout/Header/DrawerMenu.tsx`)

- إضافة عنصر "المساعد الذكي" مع أيقونة Sparkles
- تصميم مخصص للعنصر مع ألوان ذهبية مميزة
- شارة "AI" للتمييز
- متوفر لجميع الأدوار (Students, Teachers, Admins)

### 4. تحديث Layout (`Mobile/my-app/app/(tabs)/_layout.tsx`)

- إضافة شاشة ai-chat إلى التخطيط
- مخفية من التنقل السفلي - متاحة فقط من الـ Drawer

## المميزات المضافة

### تحسينات UI/UX:

- **رسالة ترحيب محسنة**: تتضمن أمثلة أكثر وتوضيح استخدامات أوسع
- **معالجة أخطاء ذكية**: رسائل مخصصة حسب نوع الخطأ
- **زر مسح المحادثة**: لإعادة تعيين المحادثة
- **تصميم مجيب**: يتكيف مع أحجام الشاشات المختلفة
- **أنيميشن Loading**: مؤشر تحميل أثناء التفكير

### تحسينات DrawerMenu:

- **تصميم مميز**: ألوان ذهبية وشارة AI مخصصة
- **أيقونة Sparkles**: تدل على الذكاء الاصطناعي
- **ترتيب منطقي**: وضع بين الأدوات المهمة

## الوظائف الأساسية

### 1. إرسال الرسائل

- كتابة النص في حقل الإدخال
- النقر على زر الإرسال أو Enter
- عرض الرسالة فوراً وانتظار الرد

### 2. استقبال الردود

- معالجة ردود API المختلفة
- عرض الأخطاء بشكل واضح
- تنسيق الرسائل بطريقة منظمة

### 3. إدارة المحادثة

- حفظ تاريخ المحادثة في الذاكرة
- إمكانية مسح جميع الرسائل
- عرض أوقات الرسائل

## التكامل مع Backend

- يستخدم نفس API endpoint: `/api/ai-chat`
- نفس تنسيق البيانات المرسلة والمستقبلة
- معالجة شاملة لحالات الخطأ

## كيفية الوصول

1. فتح الـ Drawer Menu (النقر على أيقونة الـ Menu في الهيدر)
2. النقر على "المساعد الذكي"
3. يتم فتح شاشة المحادثة الكاملة

## الاستخدام

1. **أسئلة القرآن**: "تفسير سورة الفاتحة", "معنى آية الكرسي"
2. **الأحكام الشرعية**: "أحكام الوضوء", "شروط الصوم"
3. **الأذكار والأدعية**: "دعاء الاستخارة", "أذكار الصباح"
4. **أي سؤال ديني**: يمكن السؤال عن أي موضوع إسلامي
