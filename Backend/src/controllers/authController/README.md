# مجلد authController

هذا المجلد يحتوي على جميع وظائف المصادقة (Authentication) مقسمة إلى ملفات منفصلة حسب المسؤولية.

## هيكل الملفات

### 📁 index.js
الملف الرئيسي الذي يجمع جميع وظائف المصادقة من الملفات الأخرى ويصدرها.

### 📄 login.controller.js
يحتوي على وظائف تسجيل الدخول:
- `login()` - تسجيل الدخول الرئيسي (للطلاب، المعلمين، والإداريين)
- `loginTeacher()` - تسجيل دخول المعلمين (داخلي)
- `loginAdmin()` - تسجيل دخول الإداريين (داخلي)

### 📄 register.controller.js
يحتوي على وظائف التسجيل:
- `registerTeacher()` - إضافة معلم جديد (للمسؤول فقط)

### 📄 password.controller.js
يحتوي على وظائف إدارة كلمات المرور:
- `changePassword()` - تغيير كلمة المرور للمستخدم الحالي
- `resetPassword()` - إعادة تعيين كلمة المرور (نسيت كلمة المرور)

### 📄 session.controller.js
يحتوي على وظائف إدارة الجلسات:
- `getMe()` - التحقق من صحة الرمز وإعادة بيانات المستخدم
- `logout()` - تسجيل الخروج

### 📄 verification.controller.js
يحتوي على وظائف التحقق:
- `verifyIdentity()` - التحقق من الهوية لاسترداد كلمة المرور

## الاستخدام

### قبل:
```javascript
const authController = require('./controllers/authController');
```

### بعد:
```javascript
const authController = require('./controllers/authController'); // يعمل كما هو
// أو

```

## الفوائد

✅ **تنظيم أفضل**: كل وظيفة في الملف المناسب لها  
✅ **سهولة الصيانة**: يمكن تعديل جزء معين دون التأثير على الأجزاء الأخرى  
✅ **قابلية القراءة**: كود أسهل للقراءة والفهم  
✅ **التوافق**: يعمل مع الكود الحالي دون أي تغييرات  
✅ **قابلية التوسع**: يمكن إضافة وظائف جديدة بسهولة  

## ملاحظات

- جميع الملفات تستخدم نفس التبعيات (Dependencies)
- الوظائف الداخلية (مثل `loginTeacher`, `loginAdmin`) تبقى في نفس الملف
- يمكن استخدام `index.js` للوصول إلى جميع الوظائف مباشرة
