# مجلد studentController

هذا المجلد يحتوي على جميع وظائف إدارة الطلاب مقسمة إلى ملفات منفصلة حسب المسؤولية.

## هيكل الملفات

### 📁 index.js
الملف الرئيسي الذي يجمع جميع وظائف إدارة الطلاب من الملفات الأخرى ويصدرها.

### 📄 crud.controller.js
يحتوي على عمليات CRUD الأساسية:
- `getStudents()` - جلب جميع الطلاب (محسّن للأداء - يدعم 1000 طالب)
- `getStudentById()` - جلب طالب واحد بواسطة ID
- `createStudent()` - إنشاء طالب جديد مع التحقق من الحلقة والمعلم
- `updateStudent()` - تحديث بيانات طالب
- `deleteStudent()` - حذف طالب واحد
- `bulkDeleteStudents()` - حذف مجموعة من الطلاب

### 📄 average.controller.js
يحتوي على وظائف إدارة المعدلات:
- `getStudentMonthlyAverage()` - جلب المعدل الشهري لطالب
- `getAllStudentMonthlyAverages()` - جلب جميع المعدلات الشهرية
- `calculateStudentMonthlyAverage()` - حساب وتحديث المعدل الشهري
- `getStudentOverallAverage()` - جلب المعدل الإجمالي

### 📄 absence.controller.js
يحتوي على وظائف إحصائيات الغياب:
- `getStudentsWithAbsenceStats()` - جلب الطلاب مع إحصائيات الغياب (محسّن بـ Aggregation)

### 📄 query.controller.js
يحتوي على وظائف الاستعلام والتصفية:
- `getStudentsByGroup()` - جلب الطلاب حسب الحلقة
- `getStudentsByTeacher()` - جلب الطلاب حسب المعلم
