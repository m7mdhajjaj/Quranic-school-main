# مجلد teacherController

هذا المجلد يحتوي على جميع وظائف إدارة المعلمين مقسمة إلى ملفات منفصلة حسب المسؤولية.

## هيكل الملفات

### 📁 index.js
الملف الرئيسي الذي يجمع جميع وظائف إدارة المعلمين من الملفات الأخرى ويصدرها.

### 📄 crud.controller.js
يحتوي على عمليات CRUD الأساسية:
- `getAllTeachers()` - جلب جميع المعلمين مع حلقاتهم
- `getTeacherById()` - جلب معلم واحد بواسطة ID
- `createTeacher()` - إنشاء معلم جديد مع التحقق من الحلقات
- `updateTeacher()` - تحديث بيانات معلم مع إدارة الحلقات
- `deleteTeacher()` - حذف معلم نهائياً مع تنظيف الارتباطات

### 📄 stats.controller.js
يحتوي على وظائف الإحصائيات:
- `getTeacherStats()` - جلب إحصائيات المعلمين (العدد الكلي، توزيع الخبرة، إلخ)

### 📄 utils.controller.js
يحتوي على الوظائف المساعدة:
- `calculateAge()` - حساب العمر من تاريخ الميلاد
- `generateTeacherId()` - توليد رقم معلم جديد تلقائياً (من 1000 إلى 9999)

### 📄 groupManagement.controller.js
مخصص لوظائف إدارة الحلقات المستقبلية (يمكن توسيعه لاحقاً).
