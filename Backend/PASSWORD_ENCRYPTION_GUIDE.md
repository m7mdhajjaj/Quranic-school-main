# تشفير كلمات سر الطلاب 🔐

## نظرة عامة
تم إضافة تشفير bcrypt لكلمات سر الطلاب بنفس طريقة المعلمين والإداريين لتحسين الأمان.

## ما تم تعديله ✅

### 1. ملف `studentController.js`
- ✅ إضافة `bcrypt` للتشفير
- ✅ تشفير كلمة المرور عند إنشاء طالب جديد (`createStudent`)
- ✅ تشفير كلمة المرور عند تحديث بيانات الطالب (`updateStudent`)

### 2. ملف `authController.js`
- ✅ تحديث كود تسجيل الدخول لاستخدام `bcrypt.compare()`
- ✅ إزالة الكود القديم الذي كان يدعم كلمات السر غير المشفرة

### 3. سكريبت تشفير البيانات الموجودة
- ✅ إنشاء `utils/encryptExistingPasswords.js` لتشفير كلمات سر الطلاب الموجودين

---

## كيفية تشفير كلمات السر الموجودة 🚀

### الخطوة 1: التأكد من البيئة
تأكد من وجود ملف `.env` في مجلد `Backend` مع:
```env
MONGO_URI=mongodb://localhost:27017/your-database-name
```

### الخطوة 2: تشغيل السكريبت
من مجلد `Backend`، قم بتشغيل:

```bash
node src/utils/encryptExistingPasswords.js
```

### الخطوة 3: مراجعة النتائج
سيعرض السكريبت:
- ✅ عدد الطلاب الذين تم تشفير كلمات سرهم
- ℹ️  عدد الطلاب الذين كانت كلمات سرهم مشفرة مسبقاً
- ⚠️  أي أخطاء حدثت

---

## ملاحظات مهمة ⚠️

### للطلاب الجدد:
- كلمة السر الافتراضية: **رقم الهوية** (إذا لم يتم تحديد كلمة مرور)
- يتم تشفير كلمة السر تلقائياً عند الإنشاء

### للطلاب الموجودين:
- بعد تشغيل السكريبت، يستخدم الطلاب نفس كلمة المرور القديمة لتسجيل الدخول
- إذا لم يكن لديهم كلمة مرور، سيستخدمون رقم الهوية

### الأمان:
- ✅ كلمات السر الآن مشفرة ببcrypt مع salt rounds = 10
- ✅ لا يمكن استرجاع كلمة السر الأصلية من قاعدة البيانات
- ✅ محمي ضد هجمات Rainbow Table و Brute Force

---

## مثال على الكود

### قبل التحديث ❌:
```javascript
// كلمة السر تُخزن كنص عادي
const student = new Student({
  ...studentData,
  password: req.body.password // نص عادي!
});
```

### بعد التحديث ✅:
```javascript
// تشفير كلمة السر
const rawPassword = req.body.password || req.body.idNumber;
const hashedPassword = await bcrypt.hash(rawPassword, 10);

const student = new Student({
  ...studentData,
  password: hashedPassword // مشفرة!
});
```

## استكشاف الأخطاء 🔍

### مشكلة: "الاتصال بقاعدة البيانات فشل"
**الحل:** تأكد من:
1. MongoDB يعمل
2. متغير `MONGO_URI` صحيح في `.env`

### مشكلة: "لا يمكن تسجيل الدخول بعد التشفير"
**الحل:** 
- تأكد من تشغيل السكريبت بنجاح
- تأكد من استخدام كلمة المرور الصحيحة (القديمة)
- راجع logs في الـ terminal

## الاختبار ✔️

### 1. اختبار إنشاء طالب جديد:
```bash
POST /api/students
{
  "idNumber": "123456789",
  "password": "test123",
  ...
}
```
تحقق من أن `password` في قاعدة البيانات يبدأ بـ `$2a$` أو `$2b$`

### 2. اختبار تسجيل الدخول:
```bash
POST /api/auth/login
{
  "userType": "student",
  "identifier": "100001",
  "password": "test123"
}
```
يجب أن يعمل بنجاح ويعيد token

### 3. اختبار تحديث كلمة السر:
```bash
PUT /api/students/:id
{
  "password": "newPassword123"
}
```
كلمة السر الجديدة يجب أن تُشفر تلقائياً
