# 📖 Quranic School — Learning & Management System

**Quranic School** is a web-based platform built with TypeScript and JavaScript to facilitate modern Quranic education. The application provides an easy-to-use interface and administration tools that help educators, students, and administrators manage lessons, track progress, and coordinate learning activities in both in-person and online settings.

## Key Features
- Role-based access for Students, Teachers, and Admins
- Lesson & curriculum management (create, schedule, and organize lessons)
- Recitation practice and audio/video resources
- Class scheduling and appointment/booking support
- Student progress tracking, assessments, and reporting
- Resource library for course materials, exercises, and media
- Notifications and basic communication tools
- Responsive UI and RESTful API structure for easy integrations

## Architecture & Testing
- Modular, MVC-style architecture to separate concerns and simplify maintenance
- Written primarily in TypeScript with JavaScript components
- Structured for automated testing and continuous improvement (test-friendly design)

## Who is it for?
Ideal for Quranic schools, tutors, mosques, and online educators looking for a focused platform to manage learners, lessons, and recitation progress.
